# 🛡️ AI-Based Cybercrime Prevention in Social Media

A web-based AI application developed to detect and help prevent harmful activities on social media, including abusive language, harmful images, and suspicious/fraudulent content.

Built as a **B.Tech Computer Science & Engineering final-year team project**.

---

## ✨ Features

- 📝 Abusive language detection
- 🖼️ Fake image detection
- ⚠️ User warning system
- 🔒 Comment flagging and restriction
- 👤 User-friendly web interface
